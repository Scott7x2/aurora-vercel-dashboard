Inicializacao pelo site

O usuario nao precisa baixar nada. Ele salva o token aqui, clica para ativar e a central 24h liga o bot automaticamente. O Vercel cuida do painel; o runner hospedado separadamente mantem os bots conectados ao Discord.

Adicionar bot ao servidor

Como pegar o token do seu proprio bot

  1. Acesse Discord Developer Portal.
  2. Clique em New Application, escolha um nome e confirme.
  3. Entre em Bot e clique em Add Bot, se ainda nao existir.
  4. Em Token, clique em Reset Token ou Copy Token.
  5. Cole esse token no campo acima e clique em Salvar bot.
  6. Em Bot, ative Server Members Intent para autorole e boas-vindas.
  7. Em OAuth2 > URL Generator, marque bot e applications.commands, escolha as permissoes e convide para o servidor.

Permissoes recomendadas: Manage Roles, Manage Channels, Manage Expressions, Create Private Threads, Send Messages, Use Slash Commands e Embed Links.

Variaveis para mensagens

Use nos textos de boas-vindas, verificacao, tickets e vendas.

{user}{userMention}{username}{server}{memberCount}{channel}{channelMention}{owner}{autoRole}{autoRoleMention}{verifiedRole}{verifiedRoleMention}{supportRoles}{supportRoleMentions}{product}{price}{emoji}{date}{time}

Variaveis e marcacoes

Use estes prefixos nas mensagens para marcar usuarios, cargos, canais e deixar os textos dinamicos.

Membro

{user}{userMention}{userId}{username}{user} e {userMention} marcam o usuario.

Servidor

{server}{guild}{memberCount}{owner}{owner} marca o dono do servidor.

Canais

{channel}{channelMention}{channelName}{welcomeChannel}{authChannel}{ticketChannel}{salesChannel}{channel} marca o canal usado no contexto.

Cargos

{autoRole}{autoRoleMention}{verifiedRole}{verifiedRoleMention}{supportRoles}{supportRoleMentions}Use os campos com Mention para marcar cargos.

Vendas e ticket

{product}{price}{productDescription}{ticket}{ticketId}Funcionam melhor em venda e abertura de ticket.

Extras

{emoji}{date}{time}{emoji} usa o emoji salvo na aba Identidade.
